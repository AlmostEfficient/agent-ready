# Auth.md and agent registration

Last verified: 2026-07-25

This is an optional capability for a product that genuinely supports agent registration or authentication. It was not added to the public catalogue products merely to increase their scanner score.

Before considering it:

- fetch the current Auth.md skill from the [live scanner skill index](https://isitagentready.com/.well-known/agent-skills/index.json);
- read the current [Auth.md repository](https://github.com/workos/auth.md) and [WorkOS overview](https://workos.com/auth-md);
- confirm the product has a real registration, credential, claim, and revocation model to describe.

Do not copy an old scanner prompt into production. Follow the freshness gate in `AGENTS.md`.
