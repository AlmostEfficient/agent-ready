# MCP Server Card

Last verified: 2026-07-25

This is an optional discovery document for a product that runs a real remote MCP server. A website with only WebMCP tools should not claim to have one.

Before considering it:

- fetch the current MCP Server Card skill from the [live scanner skill index](https://isitagentready.com/.well-known/agent-skills/index.json);
- inspect the current MCP specification and the linked SEP status;
- confirm the product has a real transport endpoint and capabilities to publish.

The format was still evolving when this note was verified. Do not reuse an old schema or scanner prompt without the freshness check in `AGENTS.md`.
